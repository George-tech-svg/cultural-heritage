# Complete media frames and shared interface — 4 November 2026

Images and videos retain their original proportions with black unused space. Feed captions, translated labels, expanded descriptions and action buttons reserve their actual measured space instead of covering the attachment. Small landscape screens place the media beside the details. The hide-details control restores the larger viewing area. Attachment navigation remains separate from the image, and compact actions leave room for the universal chatbot.

Homepage preview frames have explicitly bounded image boxes, including a separate category strip. Portrait images cannot enlarge the grid row and become clipped by its overflow. Shared image/video components enforce centered containment even if a caller supplies a conflicting style. Audio/document stages no longer retain the old oversized caption padding.

Web and native clients import the same shared screens and styles. Web viewport safe-area settings match the Android/iOS HTML entry. Responsive arrangements adapt to available space while preserving the same design, content, actions and navigation. Native authentication and installation still use their platform-specific adapters.
